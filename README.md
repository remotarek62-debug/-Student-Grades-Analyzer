# محلل درجات الطلاب المتعثرين

مشروع ويب باستخدام HTML وCSS وJavaScript.

## تشغيل المشروع
1. حمّل الملفات الثلاثة في مجلد واحد.
2. افتح `index.html` باستخدام أي متصفح.
3. أدخل رقم الطالب ومتوسطه ثم اضغط «إضافة طالب».

## طريقة الحساب
- الطالب متعثر إذا كان متوسطه من 40 إلى 49 شاملًا.
- تضاف 5 درجات رأفة للطالب المتعثر.
- لا يتجاوز المتوسط الجديد 50.
- الطلاب خارج هذا النطاق يظهر متوسطهم كما هو ولا تضاف لهم درجات رأفة.

## الملفات
- `index.html`: هيكل الصفحة.
- `style.css`: تنسيق الصفحة.
- `script.js`: إضافة الطلاب وحساب النتائج.
